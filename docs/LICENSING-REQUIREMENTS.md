# Licensing & IP requirements (from Josh, creative director)

Kingdoms of Aldmoor is intended for paid release on the iOS App Store.

- Only use assets (art, audio, fonts, code libraries) whose licenses allow commercial use AND redistribution inside a paid app. Prefer CC0. Avoid CC-BY-NC, CC-BY-SA, GPL code bundled into the app, or any unclear/unstated license.
- Keep CREDITS.md / LICENSES listing every asset and library with source URL, author, and license.
- No EverQuest / Daybreak names, zones, lore, item names, sprites, UI art, or sounds. Mechanics may be inspired by classic MMOs; everything else must be original.
- Public repo + GitHub Pages is for testing only; the repo will likely go private before launch.
