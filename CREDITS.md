# Credits and licenses

Kingdoms of Aldmoor is intended for a paid release. Everything shipped in the game is either original to this project or under a license that allows commercial use and redistribution inside a paid app.

No names, text, maps, sprites, UI, or sounds are copied from EverQuest or any other game. Classic MMO combat ideas (auto-attack on a delay, relative difficulty colors, coin denominations) are implemented with original numbers, names, and presentation.

## Original work

| What | Where | Terms |
| --- | --- | --- |
| Pixel art (tiles, characters, props, icons) | `tools/build-art.mjs`, output in `src/assets/` and `public/` | Original art for Kingdoms of Aldmoor. All rights reserved by the project owners. |
| Hoffender map | `src/assets/hoffender.tmj` | Original. Tiled JSON, generated by the same script so it can be edited in Tiled later. |
| Dialogue, item names, place names | `src/content/` | Original. |
| Sound effects | `src/game/audio.ts` | Original synthesis with the Web Audio API. No samples. |
